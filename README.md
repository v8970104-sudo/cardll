# cardll — оружейная мастерская на three.js

Процедурные 3D-модели оружия с модулями, баллистикой и эффектами выстрела. Все восемь стволов работают на одном движке, в одном крытом тире на 100 м и с одной библиотекой модулей. Каждая страница в `dist/` — самодостаточный HTML (three.js подгружается с unpkg), открывается двойным кликом или с любого статического сервера.

| Страница | Оружие |
|---|---|
| `dist/m416.html` | HK416 / M416, 5,56×45 |
| `dist/akm.html` | АКМ, 7,62×39 |
| `dist/ak74_modular.html` | АК-74М, 5,45×39 |
| `dist/scar-h.html` | FN SCAR-H, 7,62×51 |
| `dist/svd.html` | СВД / СВДС / СВДМ, 7,62×54R |
| `dist/mp5a3.html` | HK MP5A3, 9×19 |
| `dist/glock18c.html` | Glock 18C, 9×19 |
| `dist/remington870.html` | Remington 870, 12 калибр (картечь, дробь, пуля) |

## Сборка

```sh
node build.mjs        # собирает dist/*.html из src/
npx serve dist        # или любой другой статический сервер
```

Исходники — обычные модули, которые сборщик склеивает в один `<script type="module">`. Повторяющееся имя верхнего уровня в двух модулях — ошибка сборки (при склейке оно молча перекрыло бы прежнее).

- `src/engine/` — тир и постобработка (`scene.js`), приложение (`app.js`), интерфейс (`ui.js`), эффекты (`fx.js`), баллистика (`ballistics.js`), прицельные сетки (`reticle.js`);
- звук: у каждого семейства свой синтез — `engine/foley.js` + `gunshot.js` + `audio.js` (СВД, MP5, Glock, 870) и `engine/audio_b/` (M416, АК, SCAR); оба реализуют один интерфейс;
- `src/engine/lib/` — общая библиотека модулей: прицелы, «ласточкин хвост», фонари и ЛЦУ, рукоятки, дульные устройства;
- `src/weapons/` — модели оружия со своими прикладами, цевьями, магазинами и штатными дульными; `src/entries/` — точки входа; `src/template.html` — разметка и стили.

## Модули

Прицелы, фонари, ЛЦУ и рукоятки общие: модуль ставится на любую подходящую планку (Пикатинни, «ласточкин хвост» через кронштейн, «лапа» MP5, планка на ствольной коробке 870). Пистолетные фонари с зацепом 1913 встают и на длинные стволы. Приклады, цевья, магазины и штатные дульные — у каждого ствола свои; глушители, ДТК и компенсаторы подбираются по резьбе ствола.

## Управление

| Клавиша | Действие |
|---|---|
| Пробел, ЛКМ в прицеле | огонь (ЛКМ вне прицела — выбор детали) |
| ПКМ / F | прицеливание, V — другой прицел, N — магнифер |
| G / Shift+G | сменить прицельную сетку / цвет подсветки |
| C / Shift+C | фонарь 1 / фонарь 2 |
| Z / Shift+Z | ЛЦУ 1 / ЛЦУ 2 |
| U | заменить батареи |
| Y | трасса пули: след / трассирующие / скрыта |
| R, X, T, M, B, K | перезарядка, режим огня, досылание, магазин, сошки, приклад |
| L | день / ночь (свет в тире), H — справка |
| Q | качество: авто / высокое / среднее / низкое |

## Что моделируется

- **Баллистика**: точечная масса с таблицами сопротивления G1 (пули) и сферы (дробь/картечь), плотность воздуха, ветер, деривация, пристрелка под текущий прицел, рикошеты под скользящим углом. Попадание считается по траектории, звук удара приходит с задержкой по дальности; после выстрела показываются дальность, время полёта, скорость и энергия. Эффект попадания зависит от поверхности (сталь, бумага, бетон, дерево, пулеулавливатель) и энергии пули; при рикошете — веер искр вдоль отражённого направления.
- **Выстрел**: пламя вдоль оси и звезда с торца, струи из ДТК и компенсаторов, раскалённые частицы, пороховые газы тормозятся в воздухе и сносятся; объём газов зависит от патрона. После очереди ствол дымит, гильзы дымят из дульца и отскакивают от пола. Холодный глушитель даёт хлопок на первом выстреле.
- **Прицельные сетки**: у каждого прицела 3–4 сетки и 3 цвета подсветки. В оптике угловой масштаб честный, BDC-шкалы строятся по баллистике текущего патрона. Механический прицел, перекрытый модулем (например, ПСО-1), в список прицелов не попадает.
- **Фонари и ЛЦУ**: у каждого излучателя своя кнопка и своя батарея (тип элементов у каждой модели свой). Стабилизированный драйвер держит яркость до ~12 %, потом свет желтеет и мерцает; ступенчатый (18650) переходит на 42 %. В HUD — обратный отсчёт оставшегося времени в минутах. Если батарея садится, а второй излучатель того же типа выключен, он включается сам.
- **Тир и свет**: крытый тир на 100 м с кабинками, гонгами, IPSC и бумажными мишенями; фонарь даёт объёмный луч, подсвечивает дым и пылинки, глаз адаптируется к темноте.

## Производительность

Уровень качества выбирается по видеокарте (программный рендер и телефоны — «низкое», встроенная графика — «среднее», дискретная — «высокое») и дальше подстраивается по времени кадра: сначала снижается плотность пикселей, затем уровень. «Высокое» — исходная картинка; на остальных уровнях те же эффекты считаются дешевле: AO в половинном разрешении и с меньшим числом сэмплов, MSAA 2×, меньше карты теней и шагов объёмного луча. Кадр рисуется только когда что-то меняется; тень от неба (4096²) перерисовывается только при движении мишеней. Уровень можно задать клавишей Q или параметром `?q=low|mid|high`.

Настройки, заряд батарей, выбранные сетки и качество хранятся в `localStorage`.
