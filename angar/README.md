# ANGAR-07 — карта в ангаре

Самодостаточная страница `dist/angar_map.html` (three.js r166 и ammo.js вшиты, открывается двойным кликом).

```sh
node angar/build.mjs     # src/game.js + vendor/* → dist/angar_map.html
```

- `src/game.js` — игра (карта, свет, эффекты, физика, интерфейс);
- `src/template.html` — разметка и стили, в неё подставляются скрипты;
- `vendor/three.r166.js` — three.js с аддонами постобработки, `vendor/ammo.js` + `vendor/ammo.wasm.b64` — Bullet.

Качество: `?q=low|med|high|ultra` (по умолчанию выбирается по видеокарте и дальше подстраивается по времени кадра).

## Свет

- Статика (кровля, стены, фермы, контейнеры, hesco) отбрасывает тени от солнца: солнце попадает внутрь только через проёмы кровли, окна и ворота.
- Объёмный свет (`med` и выше): лучи солнца считаются по его карте теней, поэтому режутся фермами и укрытиями; конусы прожекторов; ореолы ламп и огня в воздухе и в дыму. Пыль блестит только в солнечных лучах. На `low` — прежние дешёвые конусы.
- Адаптивное качество при просадке отключает по очереди: AO → разрешение объёмного света → разрешение кадра → объёмный свет.

## Огонь

Цвет пламени по температуре (ядро → языки → остывающие кончики), горячее ядро у основания, длинные языки, треск искр, засветка пола под очагами (один draw call на все), ореол в дыму.

## Детализация

- Контейнеры: трапециевидная гофра геометрией, угловые фитинги, двери с запорными штангами, кулачками, рукоятками и петлями, карманы под вилы, маркировка (код владельца, 45G1, CSC), ржавые потёки.
- Бочки: профиль 200-литровой бочки с закатками и рёбрами, пробки на крышке, ржавчина по кромкам, потёки, этикетка.
- Пол: плиты 6×6 м с разнотоном, блеск от затирки, заполнитель, грязь в швах.

Вся новая геометрия запекается в общие буферы по материалам и не добавляет draw calls на объект.
