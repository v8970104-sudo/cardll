# cardll — оружейная мастерская на three.js

Процедурные 3D-модели оружия с модулями, баллистикой и эффектами выстрела. Каждая страница в `dist/` — самодостаточный HTML (three.js подгружается с unpkg), открывается двойным кликом или с любого статического сервера.

| Страница | Оружие |
|---|---|
| `dist/svd.html` | СВД / СВДС / СВДМ, 7,62×54R |
| `dist/mp5a3.html` | HK MP5A3, 9×19 |
| `dist/glock18c.html` | Glock 18C, 9×19 |
| `dist/remington870.html` | Remington 870, 12 калибр (картечь, дробь, пуля) |

## Сборка

```sh
node build.mjs        # собирает dist/*.html из src/
npx serve dist        # или любой другой статический сервер
```

Исходники — обычные модули, которые сборщик склеивает в один `<script type="module">`:

- `src/engine/` — сцена, приложение (`app.js`), интерфейс (`ui.js`), звук, эффекты (`fx.js`), баллистика (`ballistics.js`), прицельные сетки (`reticle.js`);
- `src/engine/lib/` — общие модули: прицелы, фонари и ЛЦУ, дульные устройства, рукоятки, боеприпасы;
- `src/weapons/` — модели оружия; `src/entries/` — точки входа страниц; `src/template.html` — разметка и стили.

## Управление

| Клавиша | Действие |
|---|---|
| Пробел, ЛКМ в прицеле | огонь (ЛКМ вне прицела — выбор детали) |
| ПКМ / F | прицеливание, V — другой прицел, N — магнифер |
| G / Shift+G | сменить прицельную сетку / цвет подсветки |
| C / Shift+C | фонарь 1 / фонарь 2 |
| Z / Shift+Z | ЛЦУ 1 / ЛЦУ 2 |
| U | заменить батареи |
| Y | трасса пули: след / трассирующие / скрыта |
| R, X, T, M, B, K | перезарядка, режим огня, досылание, магазин, сошки, приклад |
| L | время суток, H — справка |

## Что моделируется

- **Баллистика**: точечная масса с таблицами сопротивления G1 (пули) и сферы (дробь/картечь), плотность воздуха, ветер, деривация, пристрелка под текущий прицел, рикошеты под скользящим углом. Попадание считается по траектории, звук удара приходит с задержкой по дальности; после выстрела показываются дальность, время полёта, скорость и энергия.
- **Выстрел**: осевая вспышка и вторичный факел газов, вид с торца, раскалённые частицы пороха; дым тормозится воздухом в 0,3–1 м перед стволом и сносится ветром. Пламегаситель, компенсатор, тормоз и глушитель дают разную картину; днём вспышка почти не видна, ночью дым подсвечивается ею.
- **Прицельные сетки**: у каждого прицела 3–4 сетки и 3 цвета подсветки. В оптике угловой масштаб честный, BDC-шкалы строятся по баллистике текущего патрона. Выбор сохраняется.
- **Фонари и ЛЦУ**: у каждого излучателя своя кнопка и своя батарея. Если батарея садится, а второй излучатель того же типа выключен, он включается сам. В HUD показан обратный отсчёт оставшегося времени в минутах.

Настройки, заряд батарей и выбранные сетки хранятся в `localStorage`.
